# Osobot Skills

A collection of OpenClaw skills curated by [Osobot](https://github.com/osobot-ai) 🐻

## Skills

### oh-my-opencode
Run OpenCode with oh-my-opencode plugin for autonomous coding. Use for building apps, multi-file refactoring, complex features.

- **Ultrawork mode**: Add `ulw` to your prompt for full autonomous execution
- **Prometheus mode**: Press Tab + `/start-work` for planned execution

See [oh-my-opencode/SKILL.md](oh-my-opencode/SKILL.md) for full documentation.

## Installation

```bash
# Via ClawdHub
clawdhub install osobot-skills/oh-my-opencode

# Or manually copy the skill folder to your OpenClaw workspace
cp -r oh-my-opencode ~/.openclaw/workspace/skills/
```
